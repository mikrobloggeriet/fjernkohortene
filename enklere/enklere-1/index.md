# Mer kreativ med mer fokus?

Kreativitet handler om å koble ting man ikke hadde tenkt at hører sammen.
Men kreativitet handler også om å lage seg et tydelig regelsett man holder seg innenfor, så man fritt kan utforske rommet man er i.
Kunstnere kan lage seg intrikate regelsett de kan lage kunsten sin innenfor.
Det kan gi sjarm og eleganse.
Det blir ikke så kreativt hvis man skal male og vaske vinduer samtidig.
